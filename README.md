# 📚 Book Wrapping Reservation System

A simple desktop application for managing book-wrapping reservations.

## Features

* 👤 Manage customers
* 📚 Create book-wrapping reservations
* 💰 Calculate the total bill
* 💳 Manage payment methods
* 🔎 Search reservations
* ✏️ Edit and delete orders
* 📋 Track order status
* 🗄️ Store data using SQL Server

## 🛠️ Built With

* C#
* Windows Forms
* SQL Server
* ADO.NET
* 3-Tier Architecture
